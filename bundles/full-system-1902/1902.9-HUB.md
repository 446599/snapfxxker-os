# 1902.9: explicit Hub socket numbering

The optional `[ace]` setting `hub_port_order` lists four comma-separated
`/dev/serial/by-path/` names, in the desired display order. It is disabled
when omitted. A missing port retains its place instead of shifting later
ports; unrelated discovered ports are not assigned. Device UID remains the
identity of stored filament data and of native exit operations. It no longer
chooses the ACE display number when this setting is active.

On the currently documented U1 CH344 hub, the expected path suffixes for
J1–J4 are `1.0`, `1.2`, `1.4`, `1.6`. J2 and J4 were individually verified
in the existing hardware records; J1 and J3 should also be physically checked
before motion acceptance. The current system's complete path prefix is
`/dev/serial/by-path/platform-fed00000.usb-usb-0:1.3:`. The explicit setting
belongs in the actual device configuration, not in the packaged default:

```ini
hub_port_order: /dev/serial/by-path/platform-fed00000.usb-usb-0:1.3:1.0, /dev/serial/by-path/platform-fed00000.usb-usb-0:1.3:1.2, /dev/serial/by-path/platform-fed00000.usb-usb-0:1.3:1.4, /dev/serial/by-path/platform-fed00000.usb-usb-0:1.3:1.6
```

Changing the U1 upstream USB socket changes these path names and requires
updating the setting. An unrecognized path is not silently assigned elsewhere.

Existing per-device overrides, stored tag reads and interrupted retract
records are re-indexed with their UID. Override and interrupted-retract
payloads also have their embedded ACE index updated. Before activating the
option, back up the current configuration and check that no print, filament
operation, pending retract, or unknown head source is present. Compare the
stored data before and after the migration.

During an ACE2K reconnect the provider queries its identity before allowing
motion and before reporting the reconnect ready. If a different UID appears on
an already-known socket, that channel is held and Klipper must be restarted
while idle to establish the new mapping. A same-device reconnect is allowed.
Do not change physical connections while printing. This is a software
candidate; real port identification, a four-unit restart, reconnect behavior,
and filament paths still require hardware acceptance.
