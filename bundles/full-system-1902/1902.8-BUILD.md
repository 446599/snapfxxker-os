# 1902.8 complete candidate assembly
The full build is now explicitly separate from the old 1902.7 build. It requires a freshly compiled AArch64 screen and matching screen resources, all material runtime modules and companion routes, the exact verified base firmware, ARM64 import checks, rootfs capacity and full partition/readback checks. A failed screen build cannot fall back to the released screen. The missing compact print-tune source is replaced by a call to the maintained full PrintTuneOverlay; actual tune controls remain. Single-slot native eject uses the same confirmation and task interface as batch eject. ACE MCU images remain unchanged. The first artifact is a candidate until actual U1 boot/motion acceptance. No user files, calibration, saved color settings or printer credentials are included.
