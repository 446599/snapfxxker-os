# U1 compact print controls

These seven files restore the 480×320 Snapmaker print layout used by the
2026-11-24 screen deployment. The pinned 233-screen source has the original
print-status controller and XML branch, but lacks the companion controller
and resources. Stage the seven files before compiling rather than changing
the controller to force the generic layout. The compact selector continues
to use the original Snapmaker and display-size checks.
