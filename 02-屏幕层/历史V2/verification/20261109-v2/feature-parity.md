# V2 功能核对

以本地 multiACE 网页前端 app.js 与 FastAPI 路由为依据。

| 功能 | 机器端接入 |
|---|---|
| multi 模式喷头与同号槽位 | 自定义耗材总览 |
| 温度、湿度、颜色、材质、余量 | 总览与环境页 |
| 装料、换料、退料 | 复用已有 AMS 事务后端 |
| 线盘库新建、编辑、余量修正 | 新耗材库，使用设备宏 |
| 线盘与 ACE 槽位绑定、解绑 | 新耗材库 |
| RFID 读取与 OpenSpool 写卡 | 新耗材操作页 |
| 手动烘干 | 可见的环境页入口 |
| 自动烘干与阈值、跟随参数 | 新设置页 |
| 自动续料 | 使用 ACE_SET_QUAD_REPLENISH |
| PA 同步与 PA 标定 | 新设置页与标定入口 |
| 空打检测、取头清洁、冲刷矩阵 | 与网页版相同设置宏 |
| Spoolman 同步 | 本机服务转发网页后端 |
| U1 本地固件升级 | 完整包选择、校验、确认、系统执行器与日志 |
| 完整配置、导入导出、路径校准、预检和插件 | 继续使用网页版 |

以上接入已完成本地实现。验证记录区分模拟测试、编译及实机验收。
