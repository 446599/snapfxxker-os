# U1 触屏界面设计规范

以中文 480×320 为首要验收尺寸，同时在 800×480 运行共用组件回归。维持米白背景、浅卡片和陶土强调色。总览、控制、耗材、设置占据原来的四个底部入口，配套动作遵循原有可用条件。设备状态、连接状态、禁用原因和风险操作用文字或图标配合颜色表达。正文使用 `#text`，次级读数和说明使用 `#text_muted`。入口图标用 `#elevated_bg` 浅底，陶土色用于主要操作、选中状态及输入焦点。危险确认使用 `danger` 变体和明确的操作动词。

## 尺寸与文字

在 [globals.xml](../../ui_xml/globals.xml) 定义尺寸，在 [styles.xml](../../ui_xml/styles.xml) 定义共用外观。下表是 480×320 的目标像素值。写 XML 时引用 token。

| 用途 | Token 或组件 | 目标 |
|---|---|---:|
| 页面左右边距 | `#u1_page_pad` | 8 px |
| 同级区块和按钮间距 | `#u1_card_gap` | 8 px |
| 图标与短标签、密排控件间距 | `#u1_compact_gap` | 4 px |
| 卡片内边距 | `#u1_card_pad` / `#u1_card_pad_roomy` | 8 / 12 px |
| 标题栏、底部导航 | `#u1_header_height` / `#u1_nav_height` | 44 / 46 px |
| 常用可点击区域 | `#u1_touch_target` | 至少 44×44 px |
| 返回目标 | `#u1_header_back_width` | 64×44 px |
| 设置前导图标槽 | `styles.u1_setting_icon_slot` | 28×28 px |
| 设置入口卡片高度 | `#u1_menu_tile_height` | 64 px |
| 卡片圆角 | `#u1_card_radius` | 8 px |
| 页面标题／弹窗标题 | `#u1_heading_font`／`#font_display_small` | 20 px／20 px 粗体 |
| 正文和主按钮文字 | `#u1_body_font` | 18 px |
| 辅助文字、单位和简短状态 | `#u1_aux_font` | 16 px |

主界面顶部的设备状态条沿用 38 px（`#u1_status_height`），左侧是 18 px 粗体的入口名，右侧是联机状态和通知。二级页在其下使用 44 px 平直页头与浅色底线。标准页头在两侧能对称留位且没有可见标题徽标时几何居中显示标题，返回用 16 px 标签和箭头。打印文件视图切换和通知铃在该条内使用整条高度。这里保留竖向空间供总览卡片、控制项和底栏使用。数值读数可沿用 `#u1_title_font` 的 24 px 层级。

字号不等于实际行高。布局以字体实际测量值为准：当前 24 px 数字字体的行高为 32 px，温度读数行至少预留 32 px。固定高度按钮还要扣除边框和上下内距，不能只按字号判断是否容得下。底栏固定为 46 px，急停与烘干提示和普通导航一样使用 44 px 高度，不能再跟随宽屏通用按钮 token 放大。

耗材卡片在 110 px 宽度内保留 24×24 px 的独立编辑按钮，并向四边扩展 3 px 点击范围，以区分整卡选择与编辑。卡片标题区左右各留 4 px，完整显示 ACE 与槽号；标题下方保留大色块，材质／状态行固定在色块下方并居中；空槽显示“无耗材”，有料但没有材质记录显示“未识别”，已识别显示实际材质类型，离线保持明确标注。同排卡片色块等高，不压成细条。色块内不显示克数或文字标签；已知余量仅用颜色比例表达，未知余量保留纯色，标题和编辑按钮不随余量变化移动。颜色页在 480×320 用约 40×28 px 的 6×4 预设格和 24 px 色相条，保留取色区空间。返回、取消、确定及耗材组切换保持 44 px 点击高度。

底部导航的整格保持至少 44 px 点击高度，底栏外框和选中态统一使用 8 px 圆角，选中态用浅色填充和陶土色细边线。高亮在各自等宽格内四边统一内缩 4 px，图标文字居中，不随选中状态跳动；只高亮当前入口。按下时用浅色反馈并保持原尺寸，避免缩放导致边缘触点落到按钮外。

烘干页采用单屏布局：五个材质预设、实时仓温／湿度／运行状态、温度和时长输入，以及等宽的自动烘干／开始／停止按钮。真实数据不可用时显示“—”，请求受理后等待设备状态确认，停止入口独立于打印和进退料的开始限制。自动烘干页将启用状态、三个策略字段和保存入口放入首屏，说明文字可滚动查看。

## 共用组件

| 组件 | 放置与对齐 |
|---|---|
| `header_bar` / `overlay_panel` | 标准页头左侧是返回，中间是标题，右侧是动作。返回固定 64 px 宽、44 px 高，标题接在返回右侧并占用余宽，右侧动作按实际内容占位。标题默认单行省略，数字键盘字段名可用两行。注入动作使用已有 `header_bar-header_content` 插槽。页头底线悬浮在触控范围内且不接收点击。 |
| 带标签的页头 | 横屏移动页在左侧放返回和「移动」标题，右侧放「点动／定位／热床／设置」。可伸缩空隙吸收余宽。标签与设置使用整条 44 px 的点击高度，每项最少 44 px 宽，当前标签用强调色，页头留足空间给可操作项。 |
| `styles.u1_page` / `styles.u1_card` / `styles.u1_flat_card` | 页面容器提供背景和统一边距。`u1_card` 使用边线，`u1_flat_card` 无边线；二者共用背景和圆角，卡片内容按密度选 8 或 12 px 内距。成组卡片把余数交给 flex/grid，同行同高，同类等宽。 |
| `setting_group` / `setting_*_row` | 同组行依次设前导槽、伸缩文字区、控制槽。带图标接口的标准行空缺时保留槽位，避免同组标题左右跳动。行内两端留 12 px，标签距前导槽 8 px，浅分割线从标签列画到控件的共同右缘。开关居中，状态值右对齐，箭头在行末，短文本输入和下拉项共用约三分之一可用宽度。信息按钮与它所解释的行末控件相邻，在各类行内留出 44 px 点击区。行按内容长高。 |
| `setting_form_input` / `setting_form_dropdown` | 左侧标签可换行，右侧输入控件填满余宽，文字起点和控件高度保持一致。输入和下拉可复用 `styles.u1_settings_control` 与焦点边线。独立字段把 16 px 标签贴在字段上方，字段高至少 44 px。主机对话框使用等高的地址／端口列，API 密钥独占一行，状态跟随测试动作。 |
| `modal_header` / `modal_dialog` / `modal_button_row` | 弹窗卡片以 90% 宽度居中，通用弹窗上限 432 px。标题使用深色粗体，和可选语义图标左对齐。正文可换行，过高时只滚动内容区。页脚用浅色顶线与正文分开，双按钮等宽等高，主要操作靠右。 |
| `empty_state` | 图标与可换行的状态文字在当前容器内对中。已有重试条件时由页面放置重试操作，动作和状态文字保持配对。 |
| `numeric_keypad_panel` | 标题区显示字段，右对齐显示值和单位；四行数字键按相同高度分配，三列等宽。整数模式保留小数点所在的网格位置，避免其余按键横移。数字和删除使用中性色，确认键保留强调色。 |
| 软键盘 | U1 Warm 的字母与控制键使用浅色填充和细边线。删除、切换和关闭是中性色，数字输入的勾选键和单行文本的完成键使用陶土色。多行回车用于换行。聚焦字段需保持可见，关闭后可访问表单动作。 |

## 九类页面模板

| 类型 | 布局骨架 | 文本或空间不足 |
|---|---|---|
| 1. 总览 / 仪表卡片 | 顶部状态条 → 主读数或任务区 → 并列状态卡片 → 底部导航 | 对齐同组图标、标签、数值及单位的基线。数值、设备告警与主操作保持完整，可选信息放详情。 |
| 2. 等分入口网格 | 对称页面边距 → 2 列等宽卡片（参考 `settings_panel`） → 底部导航 | 固定同组行高。最后一张保持原列宽，剩余空位保留。在主体滚动查看更多入口。 |
| 3. 设置列表 | `overlay_panel` → 可纵滚 `overlay_content` → 主题分组 → 复用设置行 | 静态说明优先两行。紧凑行可先折叠说明，由信息按钮展开完整解释；实时状态可见。 |
| 4. 编辑表单 | 页头 → 滚动字段区 → 确认／取消固定区，按任务分组 | 标签换行，说明和错误紧邻相关字段。键盘出现时聚焦字段保持可见，能够用键盘完成键收起输入并访问保存。 |
| 5. 详情与动作区 | 页头 → 对象摘要 → 可滚信息区 → 原有动作 | 型号、IP、版本、路径及错误细节完整换行。主要操作位置稳定，设备状态变化只更新相关区域。 |
| 6. 进度 / 校准 | 页头 → 当前步骤和设备对象 → 进度区 → 可用的推进或取消操作 | 步骤变化时同一区域更新。未知进度使用进行中指示。提示和错误支持纵滚，保留停止或返回入口。 |
| 7. 确认 / 错误弹窗 | 标题和语义图标 → 独立滚动正文 → 同高页脚按钮 | 标题可显示一至两行。错误原因、风险和恢复步骤写入正文，长消息保留完整。 |
| 8. 空 / 断线状态 | 保留页头和导航 → 同一内容区中的图标及状态 → 已有恢复动作 | 分别表达空、加载、未连接、无法使用和失败。耗材空槽保留槽位，离线信息可与已知设备或槽位对应。 |
| 9. 键盘 / 数字输入 | 字段名 → 当前值与单位 → 等分按键区 → 已有提交、关闭或返回 | 长字段名至多两行。展示合法格式和输入校验提示。键盘开启与关闭后均验证焦点、数值、提交和恢复。 |

耗材页关闭 multiACE 后保留四个外置料位置对应四个喷头。开启时覆盖 ACE 0–4 台、喷头模式和断线／空槽。入口数量变化时维持卡片规格，材料编辑和颜色选择沿用各自层级。

## 长文、布局与扩展

- 把标题和入口摘要限制在明确行数内。短标签可以省略，设备身份、当前值、错误原因与安全信息应在当前页或其对应详情完整可读。
- 在纵向页面中只让内容容器滚动。使用 `height="0" flex_grow="1" scroll_dir="ver"` 给内容区分配剩余高度，页头和页脚在其外。动态说明应改变行高，禁止用负边距或位置补偿挤进固定行。
- 等分行的直接子项用 `width="0" flex_grow="1"`，同行的高度用同一 token。设置首页 [settings_panel.xml](../../ui_xml/settings_panel.xml) 的六个 `u1_settings_tile` 可作为参考。动态格子复用 `responsive_grid`，保证最窄列仍容纳控件。
- 可点击视觉图标应位于留足面积的按钮或透明槽内。扩展点击区域时测量父容器边界，检查相邻控件不会截走点击。
- 外观优先在 XML 定义；必要的原生绘制复用相同 token，例如设置分割线和软键帽。设备业务和状态在 C++，以 Subject 连接。添加新公共尺寸时查 [UI Contributor Guide](UI_CONTRIBUTOR_GUIDE.md) 的 Design Tokens，随改动更新生成的 token 表并按仓库规则检查尺寸快照。
- 保留既有 XML 控件名和状态绑定。变更共用件时检查所有通过该组件连接的正常入口，例如设置选项、键盘返回与确认，以及校准面板中的条件动作。

## 新页面实施清单

- [ ] 选定一种页面模板，列出入口、首要信息和主要动作。
- [ ] 使用现有页头、卡片／行和按钮组，记录所用尺寸 token 及必要的布局例外。
- [ ] 接入原有回调、数据 Subject 和可用条件，保留控件名及返回路线。
- [ ] 设计有数据、长内容、空、加载、异常和禁用时的呈现及后续操作。
- [ ] 确定可滚区域和边缘点击范围，执行双分辨率检查并保存证据。

## 开发验收

使用隔离的控制 socket，启动 `--test -s 480x320` 和 `--test -s 800x480` 实例。命令详见 [HELIXCTL.md](HELIXCTL.md)。下列调用用于查看已打开的页面，`$UI_SOCKET` 指向当前实例。

```sh
./build/bin/helix-screen ctl --socket "$UI_SOCKET" geom overlay_header 3
./build/bin/helix-screen ctl --socket "$UI_SOCKET" geom overlay_content 2
./build/bin/helix-screen ctl --socket "$UI_SOCKET" overflow
./build/bin/helix-screen ctl --socket "$UI_SOCKET" screenshot /tmp/u1-ui-check.png
```

- 记录页面、分辨率、主题、设备状态、路径、截图和几何输出。先从整屏截图判断标题、主要信息与操作是否清楚，再检查页边、同组卡片、标题两侧槽宽和同行文字基线。等分布局允许 1 px 的舍入差。
- 覆盖 480×320 的四大入口及二级页，覆盖 800×480 的页头、设置组、弹窗、空态、输入。增加长中文标题、长 SSID 或版本、正文超过一屏、空列表、断线、单项和满项等场景。
- 确认正常滚动后第一项、最后一项与固定操作均可达。用 `overflow` 区分设计内的滚动和被裁切的控件，再检查文字省略处是否仍可获得必要信息。
- 用实际坐标点击主要按钮及边缘，核对返回、开关、设置确认／取消、键盘完成键和已存在的危险动作保护。直接对命名控件发事件只验证回调。输入应覆盖打开前、聚焦后、完成与主动关闭后的布局和点击。实机验收另外记录触屏和显示表现。

按下反馈限制在控件内部；低性能档保持原尺寸并使用填色，标准档保留轻微缩小。触摸不留下焦点外圈。键盘和输入焦点描边向内绘制。主题 `border_radius_size` 是 0–7 的档位，不能填写像素；U1 使用 Rounded 档，页面卡片沿用 8 px 公共圆角。颜色、耗材编辑、烘干及全屏打印准备预览也在左上角返回。
