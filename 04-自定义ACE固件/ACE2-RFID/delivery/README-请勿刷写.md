# ACE2-Open RFID 离线实验构建：请勿刷写

此包仅供源码审查和离线测试。它不是正式固件，也没有在 ACE 硬件上运行。不要把其中任何映像或补丁刷入设备。

## 尚未解决的阻断

- 原厂后台 RFID 任务与更高优先级的 CMD68 处理可交错访问同一读头与共享缓冲；候选没有覆盖所有 stock SELECT 路径的统一互斥锁，不能排除相邻槽误读和内存竞争。
- 现有 MultiACE 主机把 0x0102 当 UID/重读路线，不会自动把 MCU 解码字段视为已验证数据。主机和固件间尚无已验证契约。
- 实际读卡器注册器复原、嵌入式任务栈余量、实物运行时序和 STOP/读取冲突均未验证。单元测试的硬件接口为模拟。
- 用户当前设备的已有 60O 白名单仅接受原版精确哈希；此实验版本不在其中。请勿绕过校验。

## 本次变更

- 选择出的 UID/BCC 须与原 UID 一致；认证及原始块完整双读一致后才输出材质、RGBA、重量。失败时不填 PLA 默认值，保持原有 UID-only 回退。
- 颜色取块5偏移0–3、重量取偏移4–5；未确认温度不填默认值。正确读取到的黑色不会被当成无颜色。
- 按 stock 反汇编检查接收状态、长度和 ErrorReg，扩大接收缓冲；未证明实际栈余量。
- 构建脚本增加 Thumb 半字对齐及断言。版本 V1.1.90O 是本次私有实验标记，不表示上游发布。

## 离线验证

- 在云电脑以经校验的用户原厂 1.1.31 镜像和 Debian ARM GCC 重建原版 60O，SHA-256 与已有 60O 字节完全一致：35d154abb9b6e037f9c6e10640bdce05fa62e2ecaa47fc5b3b21dac9607e5360。
- 实验映像 SHA-256：758bddd50b4f7e03e399ffa35bf8316f2c3c1f403a780e13c432bca6d8d2bb27，大小 78672 字节，CRC16/Kermit 初值 0：7A4B，IAP 初始化 0xFFFF：2497。补丁回放与映像逐字节一致；错误基底被拒绝。
- 认证失败、短读、双读不一致、UID 不一致、黑/白颜色、500g、16 字符材质及坏结果均有离线测试。原有其他标签测试 47 项通过。模拟与目标 ARM 编译不等于实机通过。
- 编译链接器对固定地址发出了 Thumb 状态警告；原始 60O 可逐字节复现，但这不能证明候选映像实际安全。

## 恢复边界

已验证的 60O 映像和原厂基底应妥善保留。若未来经批准刷写后应用仍能进入 IAP，可能可恢复原版；若应用无法启动或更新中断，可能需要拆机使用 SWD 硬件编程器，不能保证 OTA 可救回。当前没有执行任何刷写。
