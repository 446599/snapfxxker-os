# Native measurement trace and 93O design constraints

Evidence in `minimal-repair/build-analysis/stock.dis` (base app remains byte-identical at these addresses in 92O):

* 0x0800E3E0–4B2 reader state 1 initializes 60-byte contexts: +0/+4 = quiet NaN, +12/+16 = 0; 0x0800E2A4/AC reset the first word to NaN for a repeated event. `0x200018A4 + 60*lane` is the lane context selected by the native worker. 0x0800FDFC starts an identity context, writes current encoder position to +0, NaN to +4, copies selected tag identity, then initiates page read.
* In reader state 6, 0x0800E526–574 converts the same timer and overflow counter used by command 76's decoder with scale 1.2342; 0x0800E614/640 compares selected tag data with candidate records, and 0x0800E674 calls 0x0800BB00 on a matching context. BB00 accepts only an absolute delta strictly between 180 and 600, increments +16, writes an estimate at +12, and 0x0800BCC4–C8 then replaces +0 with +4. The delta is no longer recoverable from +0/+4 after acceptance.
* 0x0800E9C0–D8 returns lane context +12 in the existing GET_FILAMENT_INFO response slot corresponding to protobuf remainder. This is native model output; it is not the requested MIT spool geometry or sufficient identity/quality evidence.
* 0x0800E70C posts event 6 to one of two reader queues (lane>>1). Direct BL call sites 0x0800ABEC and 0x0800ACFA occur in preload code; this is not evidence that normal command-8 host feed starts the measurement. Dynamic callers not fully excluded. Do not start native preload merely to collect data.
* At 0x080116B6–CE the Command Processing task is created with argument 4; rfid task at 0x08011726–3A uses 2; filament move task 0x080116F4–708 uses 3. Priority alone is not an end-to-end STOP latency guarantee.

Minimal prospective 93O needs a bounded per-reader owner with per-load/connection generation, a safe event source for normal feed, validated selected UID and lane association, a correlated encoder sample before native reference is overwritten, and lifetime/STOP/remove/reverse fencing. Data storage must be proven outside the existing 60-byte contexts; no spare memory has yet been established. A hook that invents a SRAM address or reuses unproven context fields is not a safe candidate. Host retrieval after STOP can avoid introducing RF requests into its serial queue. Two simultaneous lanes sharing a reader must queue; uncertainty and collision stay ambiguous. This document is not an implementation, acceptance test, or authorization for motion.

## Normal bounded feed probe

2026-11-07: on UID 808780566/17445170/942880330, firmware 92O, internal lane 2, after fresh standby/temperature/dryer and four head-sensor checks, one 20 mm feed at 5 mm/s followed by one 20 mm reverse at the same speed completed. Both moves had STOP and fresh ready/duplicate encoder readings; encoder reported +17 and -15 mm. This leaves a +2 mm telemetry difference and does not prove exact mechanical return. Lane diagnostic words remained NaN, NaN, 0; the travel was far below one revolution and does not prove whether a longer normal feed can or cannot trigger the native worker. No preload or heat was commanded. Evidence: `live/motion20-result.json`, `live/motion20-rpc.jsonl`, `live/motion20-final-state.json`.
