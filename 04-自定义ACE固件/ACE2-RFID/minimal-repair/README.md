# ACE2 233 私有最小修复 · V1.1.91O

这是基于已验证 ACE2-Open 60O 的独立小修复，不是 unified-experiment 的发布版，也不是上游社区新版本。完整 RF 重构仍保持 NOFLASH。

## 范围

- 保留 60O 的六处 RFID hook、运动逻辑、任务调度、bootloader/IAP 边界。
- 拓竹块 5：RGBA 位于 0–3，标称重量位于 4–5（小端）；只输出已核实的直径字段，不猜测温度。
- AUTH、READ、重新选卡 UID/BCC、两次块内容都通过才发布材质和颜色；失败保留 UID-only，不再伪造 PLA。
- 为原厂无容量参数的读取函数保留 256 字节临时接收缓冲，拒绝碰撞、CRC/错误、非 128 位结果；AUTH 增补错误、定时器及 0xff 读数拒绝。
- 保留打印机已经安装的主机独立认证/原始块读取逻辑；不把所有 0x0102 当成可信耗材。

## 离线证据

工具链：容器 `ace2-rfid-offline:20261107`，ARM GCC 14.2.1。固件源自交接 source 候选，新增 AUTH 错误检查；实验版本 90O 不与本版混用。

- 原基底 SHA-256：`a468e366226e7c483d3dd96b444223e89cbf0d1b10573d42b6263843ffd6be3e`
- 原 60O：`35d154abb9b6e037f9c6e10640bdce05fa62e2ecaa47fc5b3b21dac9607e5360`
- 本版：`34a8a3c76b8e127262baf05fb22639ee9f2ce588450eb04559c1c15d506fe323`
- 78,720 字节，OTA CRC（init ffff）`0xB20B`，MD5 `b5789351ed50d97223cfd9c8f46ed535`。
- 双次 ARM 构建与补丁回放逐字节一致，ELF 无 data/bss/未解析符号。
- 原有应用区域仅 14 字节改变，均属于原六处 RFID 跳转和版本；其余包括 IAP 处理/任务、启动向量逐字节不变。镜像从 app `0x08008000` 开始，不含 bootloader；OTA 写入 staging `0x08024000`。
- 新增 AUTH 回归在修复前实际失败；修复后生产寄存器包装、0–255 接收字节边界、CRC/碰撞/长度、双读/UID/BCC 和原有六组标签测试在 ASan/UBSan 下通过。
- 独立审查未发现本次变更或刷写工具阻断项。

## 栈分析与限度

精确原厂反汇编中，任务创建 `0x080171d0` 将深度乘 4。Command Processing 栈为 350 words=1400 字节；RFID 为 400 words=1600 字节。

本版相对 60O 增加 288 字节调用栈。后台路径峰值静态估计 820 字节；命令路径 `task32 → B66C48 → FEAC16 → 9C5C64 → E7A8 200 → stub8 → decoder660` 合计 1028。另留约 204 字节架构上下文开销，命令路径余量约 168 字节。此值不是设备实测高水位，也不是所有执行路径证明。源代码 `.su` 与原厂反汇编放在本地 build-analysis/build。

原有共享读头竞争和底层阻塞风险仍在。此版是有 SWD 恢复条件的受控试验，不宣称完整并发/掉电/物理停机测试通过。

## 刷写入口

`bench_flash.py` 默认只做不刷写预检，会临时释放/恢复串口。只有 `--flash` 才升级；限定第一路、UID `808780566 / 17445170 / 942880330`、起始 `V1.1.60O`，检查空闲、烘干/自动烘干关闭、串口独占、精确镜像/恢复镜像哈希。新镜像白名单只存在于独立工具进程内，不修改 multiACE 正常升级白名单。

打印机目录 `/oem/apps/multiace/firmware-tests/20261107-minimal91O` 保存候选、原 60O、原样 OTA 库和日志。恢复镜像存在不等于已经执行自动回退。OTA 代码保持不变与实际后续 OTA 循环是两层证据；设备结果另见部署记录。
