# 97O 原生几何离线候选

基于96O完整重建，只修改 BB00 的6个 double 常量和版本数字；沿用96O的四记录地址校验。二进制对比证实，96→97仅6个8字节常量区和版本数字有差异。源码最小差异见 `geometry-and-version.diff`，验证清单见 `manifest.json`。

设 C 为原生编码器的一圈长度，`n=floor((C/(2π)-43.5)/1.75)`，每层圈数 `floor(60/1.75-1)=33`；几何长度为 `0.9*2π*33*(43.5*n+1.75*n²/2)` 毫米。原生循环逐层float累加并将结果截断成整数，和现有 MIT 模型存在微小舍入差。650余个已链接 Thumb调用、层边界前后 float32 值、三次乱序样本和原有 hook/解码回归见 `test-*-output.txt`。镜像双构建、补丁重放、向量和IAP尾标一致，未连接设备。

原生流程依旧只接受 180<C<600，保留现有10000mm下限、ctx+8 上限、排序和更新语义。BB00自身仅在首次样本写ctx+12；原生预装后处理0x0800AB5E–AB7C会在count≥2时从排序数组选取中位项并覆盖ctx+12，因此全流程不只写首次值。输出触及下限或上限表示受限，不能作为准确点值。采用固定87mm芯、60mm绕线宽、1.75mm线径、0.9系数，不证明某盘实际尺寸。stock.dis中六常量的直接PC相对引用均仅一处且位于BB00，未证明不存在间接引用。

已知 95/96 Anycubic 回退路径越读4字节、共享RF scratch、SPI及同reader双卷物理归属不在本版本范围。未进行设备、启动、光学或OTA服务验证；该镜像尚待独立审查。

校验用途：补丁生成及离线重放使用 CRC16/Kermit 初值 `0x0000`，结果 `0xA682`；原 OTA 库 `load_image` 传输校验使用同多项式、初值 `0xFFFF`，结果 `0x159D`。两者不可混用；镜像 SHA-256 和内容未变。
