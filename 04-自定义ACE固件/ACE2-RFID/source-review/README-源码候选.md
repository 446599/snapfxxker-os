# ACE2-Open 拓竹 RFID 源码候选

此包是离线源码审查材料，**不是可刷写的正式固件**。尚未实现设备级 RF 互斥；没有在设备上部署或验证。

## 候选修改

基于 Simon-CR/ace2-pro-firmware-research 固定提交 9fb5dbe08bdbe01a1f5d1e65ac46b27a1856187b：

- 验证重新选卡的 UID/BCC；认证及块 4、5 两次完整一致才输出材质和颜色；失败保留 UID-only 路径，不伪造 PLA 数据。
- 色彩取块 5 的 0–3 字节，重量取 4–5 字节；温度未确认时保持未知。
- 候选 READ 保守拒绝 CRC/错误状态和碰撞结果；接收缓冲容纳原厂 helper 的最大 uint8 计数。
- 修复构建脚本在追加奇数字节后未对齐 Thumb 指令的问题，并加入地址断言。V1.1.90O 仅为私有实验标记。

## 验证

原厂 1.1.31 基底的 SHA-256 为 a468e366226e7c483d3dd96b444223e89cbf0d1b10573d42b6263843ffd6be3e。云端 ARM 工具链重建原版 60O，结果与此前版本逐字节一致（SHA-256 35d154abb9b6e037f9c6e10640bdce05fa62e2ecaa47fc5b3b21dac9607e5360）。

候选曾编译和链接，自动生成的补丁回放与候选映像一致；原版基底检查、hook、版本、CRC 和末尾 trailer 校验通过，错误基底被拒绝。认证失败、短读、不一致、UID/BCC、黑白颜色、不同重量、错误响应等单元测试通过；原有其他标签 47 项检查通过。测试中的设备读卡器为模拟，未作实机测试。候选映像及原厂固件不在本包内。

## 未完成的关键部分

- 没有设备级全局 RF 仲裁。后台和主机命令可抢同一读头及共享缓冲；CMD14、进料路径电源切换和跨多命令隧道也必须纳入安全边界。
- 原厂互斥 API 是无限等待；持锁入队可能死锁，SPI helper 也可能无限等待。尚无经证实可用的锁状态 RAM、超时和故障恢复方案。
- CMD13 缓存快照一致性、真实栈余量与寄存器复原未验证。主机安全契约虽有默认禁用的离线原型，尚无生产调用者、设备级锁证明或实时槽位归属。
- 若将来要刷入，须先完成上述实现及独立审查、精确设备型号和基底检查、并发/掉电/读卡硬件测试以及完整恢复方案。应用无法启动时可能需要拆机 SWD，不能保证 OTA 恢复。
