# 插入预装候选：未部署

本目录以 diagnostic92/live 的主机代码和 host-candidate 停止门禁为基线，包含真实插入入口、分段运动、RF 独占候选及本地 providers 网页副本。网页副本不是实机快照，部署前需要与实际网页合并。不能直接覆盖实机。

当前代码仅对 ACE UID `(808780566,17445170,942880330)` 和 `V1.1.93O` 使用私有 CMD68 op10。写入级门禁逐 ACE 限制 RFID；确认两 reader 原始启用位、停止后台并等待各自 state=8，最后恢复。源码证据 0x0800E2C4–CA 分支跳转 0x0800E51A 可证明该 worker 的 state8 不执行本轮 SELECT，不能证明所有直接命令已完成，lease 也不自动消除 lease 前已发出的命令。

仅将已验证原生 abort 深度与本会话逐段停止、两次新鲜 READY 和相同编码器计数相加；到 390±2mm 才返回 park_verified。运动 ACK 缺失、STOP 失败、编码器不稳均不能重发或估算位置。四喷头任一触发即停止，停止后仍需编码器确认。槽位代次/串口对象确保旧会话失效；同 reader 并发变化会按已确认深度重新入队，若两槽同时有料则归属歧义。

`_preload_probe_presence` 是尚未实现的 typed 接口。只能由经过验证的原子低层探测返回 `{source:'raw_reqa_v1', state:'not_detected'|'present', verified:True}`；碰撞/短帧/错误必须返回 unknown。当前 93O SELECT code 1 混合多个失败，真实路径将其视为 unknown，不能作为离场边界。第一 Terra 的 7-bit WUPA 候选仍缺现场验证，且底层接收缓冲区边界存在 SRAM 覆盖风险，暂不可用。旧版 SELECT/原始读块底层同样缺乏有界 SPI 证明，现已禁用所有这类原始事务；真实候选目前不能识别标签或计算余量。后续需经独立审查的有界固件能力及不响应判别后才可接入。

余量只写易失状态，不写库存。PLA 估算模型假设内芯 87mm、宽 60mm、直径 1.75mm、密度 1.24g/cm³；需有效周期和可信 UID，标签上 1000g 不作余量。测试用假 IO，不能代替实际串口、光学、读卡器和槽位归属验证。运动缺 ACK 后现场实际位置不确定，不能用后来的 encoder=5 证明那一段是否运动。

离线验证：`python3 -m unittest discover -s ace2-rfid-dev-20261107/preload-feature -p 'test_*.py' -v`，40 项通过；覆盖入口、停车账本、并发队列、丢 ACK、STOP 拒绝、四头触发、两 reader 恢复、RF owner、相邻槽冲突、会话失效。仍须独立审查真实 IO、异常恢复、生产网页与硬件验证后才能考虑部署。

默认累计扫描不超过 390mm 减去已确认起始深度；满卷周长可接近 500mm，随机起点无法保证两次进入边界，故不能保证插入即得余量。后续正常装载到头可考虑延续同一会话采样，当前未接此入口。三边界和双边界均只可输出区间；同 reader 两卷当前只标记归属歧义，未实现同时识别。

原生路线对照：活动 ACE 空闲插入 `_insert_read_then_preload` 与非活动 ACE 空闲插入 `_insert_tag_read_safe` 均进入 host abort；受控验证需针对目标设备显式绕过这两个分支，不能落入额外 `_pre_load` 分支。打印中 `_insert_abort_and_queue` 是独立安全路径，不能一并关闭；还须确认旧 insert 队列不会重放。原 `rc522` 配置已被读取后忽略，不能用于关闭接管。原生方案保留固件预装事件与内部计圈，host 只监视并验证 STOP、读取计数和标签，仍需验证传感器时延、槽归属和并发；host 边沿候选则需有界 RF 探测及可靠不响应证据。用户设备当前仍为 93O 和原 host，本目录候选未部署。
