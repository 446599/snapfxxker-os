# 最小生产接入边界（离线设计，未实现）

- 针对已验证支持的 ACE 固件与指定设备，idle 插入路径的 `_insert_read_then_preload` 和 `_insert_tag_read_safe` 应按同一设备/槽/插入代次接管：保留原生 INSERT→preload，不再执行旧 C-flow 的 abort、主动 CMD68 扫描、位置修正和 `_pre_load`。其他版本与设备维持现有路径。既有队列和已注册回调要按代次失效，防止拔换/重连后旧任务执行；打印中另有 `_insert_abort_and_queue` 分支，不能误放开。
- 所有本机传感器 STOP 监督应在启动原生任务前建立，不依赖外部 HTTP；STOP 优先、绑定 ACE/slot，确认接受后仍需 fresh 全槽ready及稳定显式编码器。原生阶段可能出现短暂ready或后续自动回退，不能单个ready结束；取消、读错和失联保留不确定与锁存。插入可能独立于主机请求发生，不能只覆盖网页装载。
- 读结果应在 native 活动结束且停稳后，通过现有 GET_FILAMENT_INFO 与审查后的只读诊断接口取得；诊断接口必须严格匹配固件和UID，否则 pending。RF 状态由原生任务处理；不得在运动/STOP路径排队主动 CMD68。run5 的 count=2 是原生样本插入数，CMD13 field11 / context +12 = 330000mm 是模型输出，可能达到标签总长度上限，不能未经校验写库存或按标称1000g作余量。
- 槽位与UID关联需要会话边界与共享读头歧义判断；同读头两卷、同时插入/请求、换卷、碰撞与断连都须实测。未建立有效样本或归属时输出待测/待确认。数据结构、原生数组能否提供未封顶周长及产品状态接口由后续验证决定。
